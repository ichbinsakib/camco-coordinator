# Code of Conduct

This is internal tooling for CAMCO Manufacturing, maintained by a small
team. The expectation is simple:

- Be respectful and constructive in issues, pull requests, and reviews.
- Critique code and ideas, not people.
- Assume good faith - most disagreements here are about tradeoffs, not
  right-vs-wrong.
- Harassment, personal attacks, or discriminatory language of any kind
  will not be tolerated.

## Reporting

If something in an issue, PR, or review crosses a line, contact the
repository owner ([@ichbinsakib](https://github.com/ichbinsakib)) directly
rather than escalating in the thread.

## Scope

This applies to all project spaces - issues, pull requests, commit
messages, and code review comments on this repository.
